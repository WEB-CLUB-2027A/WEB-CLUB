# WEB CLUB

WEB CLUB is a full-stack platform for managing a web development club.

## Features

- Member Management
- Project Management
- Event Management
- Workshop Management
- News & Announcements
- Member Dashboard
- Admin Dashboard
- Authentication
- Notifications

## Technologies

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MySQL
